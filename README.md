# 청년 자산형성 계산기

청년도약계좌 유지 vs 청년미래적금(2026) 환승 실수령액을 비교하는 정적 웹 계산기.
순수 HTML/CSS/JS 단일 페이지, 빌드 과정 없음, GitHub Pages로 배포.

## 폴더 구조

```
/index.html          ← 메인: 도약 vs 미래적금 계산기
/isa/index.html      ← (예정) ISA 세금 절감 계산 메뉴  →  /isa/
/assets/             ← (예정) 공용 css·js·이미지
README.md
```

메뉴를 추가할 땐 폴더를 하나 만들고 그 안에 `index.html`을 두면
`https://<아이디>.github.io/<폴더>/` 로 바로 접근된다.

## 배포 워크플로

main 브랜치에 push하면 GitHub Pages가 자동 재배포한다(약 1분).

```bash
git add .
git commit -m "feat: 변경 내용"
git push
```

## 계산 로직 메모

- 적금 이자: 단리. `이자 = 월납입 × Σ(rate[m]/12 × m)` (월별 금리 스케줄)
- 도약계좌: 1~3년 고정 + 4~5년 변동 기본금리, 우대금리는 충족 시점부터 적용
- 정부 기여금도 동일 금리로 함께 적립 가정 (정부 발표치와 0.4% 오차로 근접)
- 중위소득: 2026년 보건복지부 고시(제2025-135호) 기준
- 미래적금 가입 자격: 중위소득 200%(2인 가구 250%) 이하

자세한 산식은 `index.html`의 `<script>` 주석 참고.
